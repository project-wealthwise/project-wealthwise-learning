# Curriculum Structure in Firebase

## Subjects

This collection contains the top level ofsubjects, for example Budgeting. Each of these subjects contains lessons and resources.

### Lessons
Each subject contains some lessons as a part of it. These lessons can have both questions and resources as a part of them.
Questions can contain as many correct and incorrect answers as desired but should have at least 4 options for multiple-choice questions.

## Resources
The resources collection might appear in multiple places. It contains documents for resources relating to lessons or subjects. The current supported types are `slideshow` google slides links and `video` youtube links.
